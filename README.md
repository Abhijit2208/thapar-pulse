# 🔴 ThaparPulse (TIET Patiala Campus OS)

> **The All-in-One Student Companion Platform for Thapar Institute of Engineering & Technology (TIET), Patiala.**

---

## 🌟 Key Features

1. **📊 75% Attendance & Safe Bunk Forecaster**
   - Implements TIET Webkiosk 75% attendance policy.
   - Dynamic calculations: *"Safe to bunk X classes"* or *"Need Y consecutive classes to reach 75%"*.
   - 1-click `+1 Attended` / `Missed` logging with animated progress meters.

2. **🚖 Thapar RideShare & Cab Matcher**
   - Split cab fares to **Rajpura Railway Station**, **Chandigarh (IXC Airport / Elante)**, **Delhi (IGI / ISBT)**, and **Patiala Station**.
   - Direct 1-click **WhatsApp** message connector.
   - Dedicated **Female-only co-passenger** filter.

3. **🍛 Hostel Mess Menus & Campus Food Guide**
   - Live daily menus for **Hostel J, M, H, and Girls Hostels (E, I, etc.)**.
   - Community dish rating (*"Edible 🔥"* vs *"Skipping to COS 🏃"*).
   - Late-night campus food spot directory (COS Kiosks, Nirvana, G-Block, Jaggi).

4. **📚 Academic Vault (MST / EST PYQs & Notes)**
   - Branch & Semester filtered repository for `UCS415`, `UCS303`, `UTA018`, `UMA010`, `UEE001`, etc.
   - Handwritten topper notes and previous year question papers.

5. **🛍️ Campus Bazaar & Lost-Found Board**
   - Buy & sell Hero Sprint cycles, ED drafters, coolers, kettles, and lab coats.
   - Tagged lost & found board for Central Library, LP halls, and TAN Audi.

6. **⚡ Societies & Events Radar**
   - Recruitment rounds, deadlines, and direct apply links for **CCS, OWASP, MLSC, Frosh, EDC, and Saturnalia/Urja** fests.

7. **💬 Anonymous Senior Advice & Placement Forum**
   - Placement interview roadmaps, hostel life banter, and branch advice with upvoting and comments.

8. **🎯 Target CGPA Simulator**
   - Calculate the exact SGPA needed this semester to graduate with your target CGPA (e.g. 8.50+).

---

## 🚀 Quick Start (Local Setup)

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Abhijit2208/thapar-pulse.git
   cd thapar-pulse
   ```

2. **Run locally using Python:**
   ```bash
   python -m http.server 5173
   ```

3. Open **[http://localhost:5173](http://localhost:5173)** in any web browser.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, Vanilla CSS3 (Glassmorphism & Custom Properties), Modular ES6 JavaScript
- **State Management**: Browser `localStorage` (offline & persistent)
- **Typography**: Google Fonts (Outfit, Inter, JetBrains Mono)
- **Theme**: Obsidian Dark & Crimson palette with light mode support
